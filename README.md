# Example BE implementation for `react-native-secure-sign `

Backend for secure registration and authentication of mobile devices (React Native) using cryptographic digital signatures. The application implements a challenge-response mechanism with ECDSA (ES256) signatures.

### Main Features

The backend offers a two-step registration/authentication process:

1. **Challenge Initiation (`/v1/register/initiate-challenge`)**
   - Generates a unique challenge with a random nonce
   - Creates an object to sign in canonical JSON format
   - Returns `challengeId` and `informationToSign_b64u` (data to sign in base64url format)
   - Challenge has a 5-minute expiration time
   - Optionally accepts device information (platform, app version)

2. **Challenge Finalization (`/v1/register/finish-challenge`)**
   - Verifies the digital signature generated by the client
   - Checks challenge validity (time and one-time use)
   - Verifies ECDSA (ES256) signature in P1363 format
   - Each challenge can only be used once

### Security

- **Algorithm**: ES256 (ECDSA with SHA-256)
- **Signature Format**: P1363 (IEEE P1363)
- **Public Key Format**: DER/SPKI
- **Challenge Expiration**: 5 minutes
- **One-Time Use**: Each challenge can only be used once
- **Canonical JSON**: Uses JSON canonicalization for data consistency

### API Endpoints

#### POST `/v1/register/initiate-challenge`

Initiates the registration process by generating a challenge to sign.

**Request Body** (optional):

```json
{
  "device": {
    "platform": "ios",
    "appVersion": "1.0.0"
  }
}
```

**Response**:

```json
{
  "informationToSign_b64u": "eyJ2ZXIiOiJTUzEiLCJhbGciOiJFUzI1NiIs...",
  "challengeId": "abc123..."
}
```

#### POST `/v1/register/finish-challenge`

Finalizes the registration process by verifying the digital signature.

**Request Body**:

```json
{
  "challengeId": "abc123...",
  "signature": "def456...",
  "publicKey": "ghi789..."
}
```

**Response**:

```json
{
  "success": true
}
```

**Errors**:

- `400 Bad Request` - Missing required fields, invalid data format
- `401 Unauthorized` - Challenge expired, already used, or signature is invalid
